# PRIMECONT — REFERENCE INDEX
> Documento de curadoria e direção de referências para a construção visual e estrutural do site institucional da PRIMECONT Contabilidade e Perícias.

---

# 1. OBJETIVO DESTE ARQUIVO

Este documento existe para transformar referências visuais em decisões práticas de construção para o site da PRIMECONT.

Ele deve orientar:
- a direção visual do site
- a estrutura das páginas
- o ritmo de espaçamento
- o nível de sofisticação
- a composição dos blocos
- o estilo dos componentes
- a linguagem institucional da interface

## Importante
As referências abaixo **não devem ser copiadas literalmente**.

Elas devem ser usadas como base para absorver:
- sensação
- lógica de construção
- hierarquia visual
- comportamento de layout
- refinamento institucional

## Regra principal
O site da PRIMECONT deve parecer:
**uma marca própria, forte, elegante e coerente**  
— e não uma mistura aleatória de referências.

---

# 2. DIREÇÃO GERAL DE REFERÊNCIA

## Sensação desejada para o site da PRIMECONT
O site deve transmitir:

- elegância institucional
- confiança
- presença
- organização
- clareza
- sofisticação silenciosa
- estrutura
- autoridade sem rigidez
- proximidade com postura profissional

## O site NÃO deve transmitir
- startup
- fintech
- consultoria genérica
- burocracia fria
- template pronto
- visual carregado
- excesso de efeitos
- clichê de contabilidade
