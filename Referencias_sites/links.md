# Links de Referências e o que você deve e não deve usar em cada um desses sites. O link é o caminho pára o site, onde você deve entrar e analisar cada um deles. E as análises embaixo é o que eu quero que você use de referência em cada um desses sites.

- https://www.cliffordchance.com/home.html
1) Clifford Chance
O que esse site faz muito bem

Esse site passa autoridade institucional imediata.

Ele não tenta “te convencer demais”.
Ele simplesmente parece:

sólido
internacional
confiável
sofisticado
muito bem estruturado

A arquitetura de navegação e a forma como a marca se posiciona como autoridade são muito fortes.

O que você deve aproveitar dele
Melhor parte para copiar:
A sensação do topo do site + hero + header
O que usar no seu site:
header minimalista e elegante
menu bem limpo
hero com muito respiro
headline forte
poucos elementos na primeira dobra
sensação de marca “séria e madura”
Como isso entra na PRIMECONT

A PRIMECONT deve usar essa referência para construir:

seu:
header
hero
tom institucional
espaçamento da primeira dobra
O que NÃO copiar

Não copie:

o excesso de profundidade institucional/corporativa global
navegação muito pesada
linguagem fria demais

Porque para a PRIMECONT você ainda precisa manter:

proximidade
acessibilidade
atendimento humano
Nota para o seu projeto
Use MUITO como referência de:

sensação premium institucional
