# PRIMECONT — ABOUT VISUAL REFERENCE SYSTEM
> Sistema oficial de referências visuais da página Quem Somos da PRIMECONT Contabilidade e Perícias.

---

## 1. OBJETIVO DESTE ARQUIVO

Este arquivo define, de forma oficial, **quais sites devem ser usados como referência visual para a página Quem Somos da PRIMECONT** e **qual parte de cada site deve inspirar cada bloco da página**.

Este documento existe para evitar que a página Quem Somos seja construída de forma genérica, fria ou sem direção institucional clara.

A função deste arquivo é garantir que a página Quem Somos tenha:

- sofisticação institucional
- narrativa elegante
- confiança visual
- proximidade na medida certa
- consistência com a Home
- maturidade de marca
- acabamento premium

---

# 2. REGRA CENTRAL DE USO

A página Quem Somos da PRIMECONT **não deve copiar literalmente** nenhum dos sites abaixo.

Ela deve fazer uma **junção estratégica das melhores características visuais e narrativas** de cada referência.

O objetivo é construir uma página institucional que transmita:

- história
- confiança
- presença
- relacionamento
- maturidade
- elegância
