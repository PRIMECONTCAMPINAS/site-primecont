# PRIMECONT — HOME VISUAL REFERENCE SYSTEM
> Sistema oficial de referências visuais da Home da PRIMECONT Contabilidade e Perícias.

---

## 1. OBJETIVO DESTE ARQUIVO

Este arquivo define, de forma oficial, **quais sites devem ser usados como referência visual para a Home da PRIMECONT** e **qual parte de cada site deve inspirar cada bloco da Home**.

Este documento existe para evitar que a Home seja construída com referências soltas, genéricas ou contraditórias.

A função deste arquivo é garantir que a Home da PRIMECONT tenha:

- consistência visual
- direção premium clara
- sofisticação institucional
- hierarquia elegante
- acabamento refinado
- composição de blocos mais madura

---

# 2. REGRA CENTRAL DE USO

A Home da PRIMECONT **não deve copiar literalmente** nenhum site.

Ela deve fazer uma **junção estratégica das melhores qualidades visuais** de cada referência abaixo.

O objetivo é criar uma Home original, mas com uma direção visual muito bem orientada.

# 7. O QUE A HOME DA PRIMECONT NÃO DEVE PARECER

Mesmo usando as referências acima, a Home da PRIMECONT **não deve parecer**:

- site jurídico frio
- escritório contábil genérico
- fintech / startup SaaS
- página institucional burocrática
- agência visualmente barulhenta
- site corporativo americano excessivamente pesado
- layout de template
