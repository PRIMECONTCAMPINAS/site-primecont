# PRIMECONT — DIFERENCIAIS VISUAL REFERENCE SYSTEM
> Sistema oficial de referências visuais da página Diferenciais da PRIMECONT Contabilidade e Perícias.

---

## 1. OBJETIVO DESTE ARQUIVO

Este arquivo define, de forma oficial, **quais sites devem ser usados como referência visual para a página Diferenciais da PRIMECONT** e **qual parte de cada site deve inspirar cada bloco da página**.

Este documento existe para garantir que a página Diferenciais não seja construída como uma lista genérica de “vantagens” ou um bloco vazio de promessas institucionais.

A função desta página é mostrar, com clareza e sofisticação, **por que a experiência com a PRIMECONT é diferente na prática**.

A página deve transmitir:

- confiança
- proximidade
- presença
- organização
- consistência
- relacionamento de longo prazo
- maturidade no atendimento

Ela não deve parecer apenas “uma página de benefícios”.

Ela deve parecer:

**a tradução visual e institucional da forma como a PRIMECONT se relaciona, sustenta e acompanha seus clientes ao longo do tempo.**

---

# 2. REGRA CENTRAL DE USO

A página Diferenciais da PRIMECONT **não deve copiar literalmente** nenhum dos sites abaixo.

Ela deve fazer uma **junção estratégica das melhores características visuais, relacionais e institucionais** para construir uma página clara, elegante, humana na medida certa e altamente confiável.

O objetivo é fazer o visitante sentir:

- “Esse escritório parece realmente presente.”
- “Aqui eu não vou me sentir largado.”
- “Eles têm estrutura, mas também proximidade.”
- “Parece um parceiro, não apenas um prestador.”
