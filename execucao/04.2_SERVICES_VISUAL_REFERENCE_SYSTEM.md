# PRIMECONT — SERVIÇOS VISUAL REFERENCE SYSTEM
> Sistema oficial de referências visuais da página Serviços da PRIMECONT Contabilidade e Perícias.

---

## 1. OBJETIVO DESTE ARQUIVO

Este arquivo define, de forma oficial, **quais sites devem ser usados como referência visual para a página Serviços da PRIMECONT** e **qual parte de cada site deve inspirar cada bloco da página**.

Este documento existe para garantir que a página Serviços não seja construída como uma listagem comum de entregas ou um catálogo técnico genérico.

A função desta página é mostrar, com sofisticação e clareza, **como a PRIMECONT transforma sua estrutura contábil, fiscal e trabalhista em suporte real para a rotina da empresa**.

A página deve transmitir:

- estrutura
- suporte contínuo
- organização
- clareza operacional
- confiança técnica
- previsibilidade
- apoio ao empresário

Ela não deve parecer apenas “uma página do que está incluso”.

Ela deve parecer:

**um modelo de atendimento sólido, bem estruturado, premium e feito para trazer tranquilidade à operação do cliente.**

---

# 2. REGRA CENTRAL DE USO

A página Serviços da PRIMECONT **não deve copiar literalmente** nenhum dos sites abaixo.

Ela deve fazer uma **junção estratégica das melhores características visuais e estruturais** para construir uma página clara, elegante, institucional e muito bem organizada.

O objetivo é fazer o visitante sentir:

- “Eles têm um método.”
- “Parece tudo muito organizado.”
- “Consigo entender o que está incluso sem parecer técnico demais.”
- “Parece uma empresa que sustenta bem a operação.”
