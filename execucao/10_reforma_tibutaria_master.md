# PRIMECONT — REFORMA TRIBUTÁRIA VISUAL REFERENCE SYSTEM
> Sistema oficial de referências visuais da página Reforma Tributária da PRIMECONT Contabilidade e Perícias.

---

## 1. OBJETIVO DESTE ARQUIVO

Este arquivo define, de forma oficial, **quais referências visuais devem guiar a construção da página Reforma Tributária da PRIMECONT** e **qual parte de cada site deve inspirar cada bloco da página**.

O objetivo é garantir que esta página não seja construída como:

- uma página genérica de conteúdo fiscal
- uma página com cara de blog
- uma página excessivamente técnica
- uma página jurídica e fria
- uma página burocrática
- uma página “explicativa demais” e pouco estratégica

A página **Reforma Tributária** precisa transmitir uma combinação muito específica entre:

- autoridade institucional
- clareza prática
- visão consultiva
- organização
- atualização
- segurança
- leitura estratégica
- apoio ao empresário

Esta é uma página que precisa parecer:

**atual, premium, confiável, clara e orientada à decisão.**

---

# 2. REGRA CENTRAL DE USO

A página Reforma Tributária **não deve copiar literalmente** nenhum dos sites abaixo.

Ela deve fazer uma **junção estratégica das melhores características visuais, estruturais e institucionais** para construir uma página própria, consistente com a marca PRIMECONT.

O objetivo é que o visitante sinta:

- “Eles entendem esse tema.”
- “Eles sabem traduzir isso para a empresa.”
- “Eles parecem preparados para orientar.”
- “Isso está claro e bem organizado.”
- “Quero entender meu impacto com eles.”
