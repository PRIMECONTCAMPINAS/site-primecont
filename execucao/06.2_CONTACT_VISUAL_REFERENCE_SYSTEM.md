# PRIMECONT — CONTATO VISUAL REFERENCE SYSTEM
> Sistema oficial de referências visuais da página Contato da PRIMECONT Contabilidade e Perícias.

---

## 1. OBJETIVO DESTE ARQUIVO

Este arquivo define, de forma oficial, **quais sites devem ser usados como referência visual para a página Contato da PRIMECONT** e **qual parte de cada site deve inspirar cada bloco da página**.

Este documento existe para garantir que a página Contato não seja construída como uma página simples de formulário, fria ou genérica.

A função desta página é transformar o contato com a PRIMECONT em uma experiência:

- elegante
- confiável
- simples
- premium
- acolhedora na medida certa
- organizada
- institucional

A página deve transmitir:

- facilidade de acesso
- confiança no primeiro contato
- proximidade
- clareza
- segurança
- disponibilidade

Ela não deve parecer apenas “um formulário de leads”.

Ela deve parecer:

**um convite bem estruturado para iniciar uma relação de confiança com a PRIMECONT.**

---

# 2. REGRA CENTRAL DE USO

A página Contato da PRIMECONT **não deve copiar literalmente** nenhum dos sites abaixo.

Ela deve fazer uma **junção estratégica das melhores características visuais, institucionais e relacionais** para construir uma página clara, elegante, acessível e premium.

O objetivo é fazer o visitante sentir:

- “É fácil falar com eles.”
- “Parece um escritório acessível e confiável.”
- “O contato parece bem organizado.”
- “Não parece um formulário frio de captação.”
