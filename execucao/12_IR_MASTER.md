# PRIMECONT — DECLARAÇÃO DE IMPOSTO DE RENDA VISUAL REFERENCE SYSTEM
> Sistema oficial de referências visuais da página Declaração de Imposto de Renda da PRIMECONT Contabilidade e Perícias.

---

## 1. OBJETIVO DESTE ARQUIVO

Este arquivo define, de forma oficial, **quais referências visuais devem guiar a construção da página Declaração de Imposto de Renda da PRIMECONT** e **qual parte de cada site deve inspirar cada bloco da página**.

O objetivo é garantir que esta página não seja construída como:

- uma página genérica de IR
- uma página promocional superficial
- uma página sazonal sem força institucional
- uma página burocrática
- uma página fria
- uma página improvisada
- uma página de “despachante”

A página **Declaração de Imposto de Renda** precisa transmitir uma combinação muito específica entre:

- confiança
- clareza
- organização
- acolhimento
- praticidade
- segurança
- orientação
- responsabilidade

Esta é uma página que precisa parecer:

**institucional, acessível, organizada, confiável e tranquilizadora.**

---

# 2. REGRA CENTRAL DE USO

A página Declaração de Imposto de Renda **não deve copiar literalmente** nenhum dos sites abaixo.

Ela deve fazer uma **junção estratégica das melhores características visuais, estruturais e institucionais** para construir uma página própria, consistente com a marca PRIMECONT.

O objetivo é que o visitante sinta:

- “Isso parece seguro.”
- “Consigo entender facilmente.”
- “Não parece complicado.”
- “Eles parecem organizados e confiáveis.”
- “Quero resolver isso com eles.”
