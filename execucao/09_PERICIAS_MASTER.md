# PRIMECONT — PERÍCIA CONTÁBIL VISUAL REFERENCE SYSTEM
> Sistema oficial de referências visuais da página Perícia Contábil da PRIMECONT Contabilidade e Perícias.

---

## 1. OBJETIVO DESTE ARQUIVO

Este arquivo define, de forma oficial, **quais referências visuais devem guiar a construção da página Perícia Contábil da PRIMECONT** e **qual parte de cada site deve inspirar cada bloco da página**.

O objetivo é garantir que esta página não seja construída como uma página genérica de serviço contábil, nem como uma página jurídica fria ou excessivamente técnica.

A página **Perícia Contábil** precisa transmitir uma combinação muito específica entre:

- sofisticação institucional
- rigor técnico
- clareza de leitura
- confiança
- autoridade silenciosa
- organização
- seriedade
- segurança

Esta é uma das páginas mais sensíveis do site.

Por isso, o resultado final precisa parecer:

**premium, técnico, confiável, claro e muito bem estruturado.**

---

# 2. REGRA CENTRAL DE USO

A página Perícia Contábil **não deve copiar literalmente** nenhum dos sites abaixo.

Ela deve fazer uma **junção estratégica das melhores características visuais, institucionais e estruturais** para construir uma página própria, consistente com a marca PRIMECONT.

O objetivo é que o visitante sinta:

- “Isso parece sério.”
- “Isso parece técnico.”
- “Isso parece bem fundamentado.”
- “Eles sabem conduzir esse tipo de análise.”
- “É um escritório confiável para tratar algo sensível.”
