# PRIMECONT — CONTABILIDADE ELEITORAL VISUAL REFERENCE SYSTEM
> Sistema oficial de referências visuais da página Contabilidade Eleitoral da PRIMECONT Contabilidade e Perícias.

---

## 1. OBJETIVO DESTE ARQUIVO

Este arquivo define, de forma oficial, **quais referências visuais devem guiar a construção da página Contabilidade Eleitoral da PRIMECONT** e **qual parte de cada site deve inspirar cada bloco da página**.

O objetivo é garantir que esta página não seja construída como:

- uma página política
- uma página de campanha
- uma página eleitoral promocional
- uma página jurídica fria
- uma página genérica de serviços
- uma página burocrática
- uma página improvisada

A página **Contabilidade Eleitoral** precisa transmitir uma combinação muito específica entre:

- rigor técnico
- organização
- segurança
- responsabilidade
- clareza
- controle
- suporte confiável
- condução séria

Esta é uma página que precisa parecer:

**institucional, sólida, organizada, confiável e muito segura.**

---

# 2. REGRA CENTRAL DE USO

A página Contabilidade Eleitoral **não deve copiar literalmente** nenhum dos sites abaixo.

Ela deve fazer uma **junção estratégica das melhores características visuais, estruturais e institucionais** para construir uma página própria, consistente com a marca PRIMECONT.

O objetivo é que o visitante sinta:

- “Eles parecem preparados para conduzir isso corretamente.”
- “Esse serviço exige responsabilidade, e essa página transmite isso.”
- “Eles parecem organizados e confiáveis.”
- “Consigo entender a importância da prestação de contas.”
- “Posso confiar essa frente a eles.”
