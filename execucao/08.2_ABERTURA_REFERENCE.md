# PRIMECONT — ABERTURA DE EMPRESA INSPIRATION BOARD
> Curadoria visual oficial de inspirações para a página Abertura de Empresa da PRIMECONT Contabilidade e Perícias.

---

# 1. OBJETIVO DESTE ARQUIVO

Este arquivo existe para consolidar, de forma mais visual e inspiracional, **quais referências devem guiar a estética, a atmosfera, o ritmo visual e a sensação geral da página Abertura de Empresa da PRIMECONT**.

Enquanto o arquivo de **Visual Reference System** define tecnicamente **qual site inspira cada bloco**, este arquivo existe para servir como:

- painel de direção visual
- referência de linguagem estética
- apoio de composição
- alinhamento de atmosfera
- guia de “sensação final” da página

Este material deve ser usado para garantir que a página tenha uma construção visual coerente, premium, institucional e mais memorável.

---

# 2. SENSAÇÃO QUE ESTA PÁGINA DEVE GERAR

A página **Abertura de Empresa** da PRIMECONT deve transmitir a sensação de que:

- existe um caminho claro
- existe alguém conduzindo o processo
- a burocracia será simplificada
- o empresário terá apoio
- a empresa será estruturada corretamente
- tudo será feito com organização e segurança

A página precisa parecer:

- elegante
- institucional
- acessível
- clara
- premium
- segura
- acolhedora na medida certa
- bem estruturada

Ela **não pode** parecer:

- uma landing page promocional barata
- uma página fria de despachante
- um site burocrático
- um site jurídico pesado
- uma página de tráfego pago genérica
- uma página visualmente pobre

---

# 3. DIREÇÃO VISUAL GERAL DA PÁGINA

A página deve combinar:

## 3.1 Sofisticação institucional
A página precisa transmitir confiança desde a primeira dobra.

## 3.2 Clareza operacional
O visitante precisa entender rapidamente:

- o que a PRIMECONT resolve
- para quem esse serviço serve
- como o processo funciona
- como entrar em contato

## 3.3 Sensação de orientação
A estética da página deve fazer o visitante sentir que:

**“eu não estou sozinho nesse processo.”**

## 3.4 Elegância silenciosa
A página deve parecer madura, organizada e refinada, sem excesso de elementos visuais.

# 5. COMO ESSAS REFERÊNCIAS DEVEM SE FUNDIR

A página **não deve parecer um recorte de vários sites**.

Ela deve parecer **uma única experiência coesa** construída a partir da fusão dessas cinco direções.

A lógica ideal é:

## Base da página
**Withum + Atlassian**

Para garantir:
- clareza
- estrutura
- boa leitura
- organização

## Camada premium institucional
**Clifford Chance**

Para garantir:
- autoridade
- sofisticação
- headline forte
- presença visual

## Camada relacional
**MBE Wealth**

Para garantir:
- proximidade
- acolhimento
- CTA mais humano
- confiança de contato

## Camada de acabamento
**Betts Diplas**

Para garantir:
- refinamento
- leveza visual
- estética mais premium
- acabamento silencioso
