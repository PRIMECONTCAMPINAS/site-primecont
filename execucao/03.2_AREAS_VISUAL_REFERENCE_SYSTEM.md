# PRIMECONT — ÁREAS DE ATUAÇÃO VISUAL REFERENCE SYSTEM
> Sistema oficial de referências visuais da página Áreas de Atuação da PRIMECONT Contabilidade e Perícias.

---

## 1. OBJETIVO DESTE ARQUIVO

Este arquivo define, de forma oficial, **quais sites devem ser usados como referência visual para a página Áreas de Atuação da PRIMECONT** e **qual parte de cada site deve inspirar cada bloco da página**.

Este documento existe para garantir que a página Áreas de Atuação não seja construída como uma página genérica de serviços ou uma lista fria de departamentos.

A função desta página é apresentar, com clareza e sofisticação, as frentes que sustentam a operação dos clientes da PRIMECONT.

A página deve transmitir:

- estrutura
- organização
- clareza
- confiança
- suporte contínuo
- maturidade operacional
- visão integrada da empresa

Ela não deve parecer apenas “uma lista do que o escritório faz”.

Ela deve parecer:

**uma estrutura institucional bem organizada, confiável e feita para apoiar o empresário com segurança.**

---

# 2. REGRA CENTRAL DE USO

A página Áreas de Atuação da PRIMECONT **não deve copiar literalmente** nenhum dos sites abaixo.

Ela deve fazer uma **junção estratégica das melhores referências visuais e estruturais** para criar uma página clara, elegante, premium e altamente compreensível.

O objetivo é fazer o visitante sentir:

- “Eles têm estrutura.”
- “Existe organização no que entregam.”
- “Parece fácil entender como atuam.”
- “Parece um escritório sólido e bem montado.”
