# PRIMECONT - Site Institucional

Repositório do site oficial e institucional da **PRIMECONT Contabilidade e Perícias**.

---

## Passo a Passo para acessar em um novo computador

Para continuar trabalhando neste projeto em outra máquina, siga os passos abaixo para baixar (clonar) todo o código com segurança.

1. Abra o **Terminal** ou **Prompt de Comando** no seu novo computador (na pasta onde você quer que o projeto fique salvo).
2. Copie o comando abaixo, cole no seu terminal e aperte `Enter`:

```bash
git clone https://github.com/gustavoalves-ia/site-primecont.git
```

3. Uma nova pasta chamada `site-primecont` será criada com todos os arquivos atualizados.
4. É só abrir essa pasta no seu editor de código e continuar programando!

---
*Para enviar novas atualizações de volta para a nuvem após terminar de trabalhar, use os comandos padrão do Git (add, commit, push).*
